# 骨骼阻尼追踪批量配置（中文版）

在 3D 视口侧边栏**一键为选中骨骼批量添加阻尼追踪（Damped Track）约束**，支持按骨骼深度 / 链条长度生成递增或递减的影响值，并内置"选中子链""高亮命中骨骼"等便捷功能，适合为布料、头发、尾巴等骨骼链快速搭建跟随/阻尼效果。

## 功能特性

- **批量添加阻尼追踪约束**：选中目标（骨骼/物体）后一键批量配置
- **选中子链**：姿态模式选中父级骨骼，自动包含整条子链（如选中骨盆即覆盖整条腿链）
- **递增 / 递减影响值**：按骨骼层级深度或链条比例生成渐变权重，可整体调整强度
- **高亮命中骨骼**：点击后在姿态模式高亮显示本次操作将命中的骨骼，不做任何修改
- **安全更新 / 清理**：本插件创建的约束统一使用「阻尼追踪_」前缀命名，只更新/清理自己创建的约束，不误动其他手K约束
- 兼容 Blender 4.x / 5.0

## 安装

与英文版**二选一**安装（两者 ID 相同，后装的会替换先装的，请勿同时安装）：

1. Blender → 编辑 → 偏好设置 → 扩展（Get Extensions）→ 右上角 **≡** → **从磁盘安装**（Install from Disk）；
2. 选择下载的 `.zip`，启用 **骨骼阻尼追踪批量配置（中文版）**。

> 传统方式：Blender → 编辑 → 偏好设置 → 插件 → 安装，选择 `.zip` 即可。

## 使用

1. 选中骨架，进入姿态模式并选中目标骨骼；
2. 3D 视图右侧 N 面板「Bone Damped Track」标签页；
3. 设置目标与影响值模式（可先【高亮命中骨骼】预览）→ 点击【批量添加阻尼追踪】。
